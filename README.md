# Auto Daily Report

Otomatisasi laporan harian klinik.

### Masalah
Setiap hari staff klinik harus rekap data Excel manual, makan waktu 1 jam dan sering salah hitung.

### Solusi
Saya membuat script Python yang otomatis membersihkan data, menghapus duplikat, dan membuat rekap kunjungan harian dalam 5 detik.

### Teknologi
- Python
- Pandas

### Cara Pakai
1. Taruh file `data_kotor.xlsx` di folder yang sama
2. Jalankan `python main.py`
3. Hasilnya jadi `laporan_bersih.xlsx`
